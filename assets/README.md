# Biblioteca visual

Esta pasta preserva a organização do kit piloto e diferencia **referência visual**, **material de extração** e **asset de produção**.

| Pasta | Conteúdo | Status inicial |
|---|---|---|
| `00_reference/` | moodboards, recortes e estudos | Conceito |
| `01_creatures/` | linhagens e animações | Protótipo |
| `02_cards/` | cartas comuns e assinatura | Conceito |
| `03_world/` | dungeon e rancho | Conceito |
| `04_ui/` | desktop e interface do Sistema | Conceito |
| `05_fx/` | efeitos de combate/despertar | Conceito |
| `metadata/` | manifesto e paleta | Versão inicial |

**Nenhum asset de conceito deve ser tratado como pronto para distribuição.** Nomes e efeitos escritos nas pranchas de IA não definem gameplay.

O conjunto completo de prévias e pranchas foi gerado como ZIP em conversa anterior. O GitHub será alimentado incrementalmente com arquivos revisados, sem assumir que tudo está importado.
