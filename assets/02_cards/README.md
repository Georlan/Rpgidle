# Cartas

- `techniques/`: técnicas automáticas de criaturas; 3 equipadas por criatura.
- `signature/`: Carta de Assinatura do treinador, uma ativa para a equipe inteira.

Separar moldura, arte, ícones e textos editáveis. Cartas mostradas em moodboards não estabelecem efeitos, raridades ou mecânicas aprovadas. Ver `docs/SYSTEM_SIGNATURE.md`.
