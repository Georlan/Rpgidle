# Agent instructions — Rpgidle

This repository is a commercial **Godot 4.6.1** creature RPG in pre-production.
Read `docs/GAME_DESIGN.md`, `docs/SYSTEM_SIGNATURE.md` and `docs/OPEN_DECISIONS.md` before gameplay decisions.

For visual, Godot, control, publishing or asset tasks, follow:
**[.agents/skills/rpgidle-production/SKILL.md](.agents/skills/rpgidle-production/SKILL.md)**.

The public references are indexed in `docs/REFERENCE_RESEARCH.md`. They are for analysis; **do not copy proprietary game IP, vendor libraries without verifying their licenses, or blindly install external skills**.

Rules:
1. Preserve the previously approved 3-creature / four-attribute / four-grade / trainer-signature model.
2. Treat formulas in screenshots, concept boards and mock data as unapproved.
3. Use reproducible input/data and honest status of assets (concept vs final).
4. Keep changes small; run automated tests, then visual QA. CI green alone is not visual approval.
5. Do not merge broken PRs, add secrets or spend money. The user owns commercial/release decisions.
