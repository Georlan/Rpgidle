# Direção visual — piloto v0.1

**Proposta:** pixel art 2D de fantasia arcana. Criaturas amigáveis no desktop e transformações fortes na dungeon; linguagem de códice para o Sistema, sem interface holográfica genérica.

## Princípios

1. **Silhueta primeiro:** cada forma precisa ser reconhecível em tamanho pequeno.
2. **Linhagem reconhecível:** manter elementos visuais de família entre ramificações.
3. **Uma leitura por tela:** modo desktop quase sem UI; gestão detalhada apenas na janela expandida.
4. **Sinal > ruído:** reservar partículas e brilho para evolução e rompimento de Potencial, não para todo clique.
5. **Cosméticos modulares:** paletas, acessórios e efeitos visuais sem alterar hitbox ou estatísticas.
6. **Pixel grid consistente:** corrigir sprites gerados por IA antes da produção; não usar pranchas conceituais inteiras como UI real.
7. **Semântica de status:** cartas comuns e Carta de Assinatura devem parecer categorias distintas, com hierarquia legível.
8. **Acessibilidade:** ícones nunca dependerão só de cor; boa leitura no monitor durante multitarefa.

## Três experiências visuais

- **Desktop compacto:** 1–3 sprites visíveis, progresso mínimo e modo ocultável.
- **Janela expandida:** rancho, árvore evolutiva, atributos, técnicas e decisão da dungeon.
- **Arena/replay:** três contra três, leitura clara de ações, prioridade para legibilidade e desempenho.
